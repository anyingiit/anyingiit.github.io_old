## About The Project

Every page in this tree — `index.html`, the dated post pages under `2019/`, `2021/`, and `2022/`, and every page under `archives/` and `tags/` — carries the same `<meta name="generator" content="Hexo 5.4.0">` tag, and the repository ships the already-compiled `css/main.css`, the `js/` bundle, and the third-party libraries under `lib/` alongside them. This is Hexo's rendered output, not a project with source to build.

`CNAME` records `blog.anyingiit.com`, the domain this output used to be served from. The Hexo configuration, NexT theme setup, and Markdown post source that produced these pages live in a separate repository, not here — this one only ever received the finished build, which is also why its own `pages build and deployment` run now fails: there is nothing left in this repository for GitHub Pages to build.

See the [open issues](https://github.com/anyingiit/anyingiit.github.io_old/issues) for planned features and known issues.

## Getting Started

### Prerequisites

- Nothing to install: every page is already rendered static HTML, CSS, and JavaScript (for example `index.html` and `css/main.css`), so any modern web browser, or any static file server, can serve it as-is.
- No source-control client, package manager, or build tool is required — there is no manifest anywhere in this repository for one to act on.

### Installation

```sh
git clone https://github.com/anyingiit/anyingiit.github.io_old.git
cd anyingiit.github.io_old
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in a browser. There is no dependency to install and no build step to run: every file in the tree, including `index.html`, is already the finished output Hexo produced.

## Usage

Open `index.html` directly in a browser, or serve the directory as shown above and browse to `/archives/` or `/tags/` to page through the old post list. Nothing here accepts flags or arguments; it is a static snapshot of a blog, not a program.
